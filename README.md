# labops-voronka — Воронка найма: недельный отчёт по найму и отказам

Загрузи выгрузку из HR-системы или таблицу кандидатов — капсула строит отчёт:
кандидаты по этапам и вакансиям, конверсия воронки, причины отказов, 3 вывода для планёрки.

**Что получаешь:**
- Таблица кандидатов по этапам и рекрутёрам.
- Конверсия воронки: где теряем людей и сколько.
- Причины отказов по темам.
- Доля принятых офферов и среднее время закрытия (если есть в данных).
- 3 конкретных вывода для планёрки.
- HTML-отчёт для хранения и показа.

## Как поставить

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-voronka
/plugin install voronka@labopsai-voronka
```

Напиши: **«Воронка»**.

### Claude (claude.ai, приложение)

1. Customize → Plugins → Add marketplace.
2. Вставь ссылку: `DianaMarshrut/labops-voronka`
3. Установи плагин «voronka».
4. Напиши: **«Воронка»**.

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-voronka
```

Через `/plugins` → Install → новая сессия → напиши: **«Воронка»**.

### ChatGPT (через проект)

1. Создай проект «Воронка найма» в ChatGPT.
2. Загрузи файл `chat-instruction.md` в файлы проекта.
3. Напиши: **«Воронка»**.

## Откуда берём данные

| Вариант | Как работает |
|---|---|
| Выгрузка из HR-системы | Excel/CSV из Хантфлоу, Поток, E-Staff, СберПодбор — загрузи файлом [проверить пути экспорта в каждой системе] |
| Google Таблица | Коннектор Google Drive в настройках чата, или экспорт CSV |
| Битрикс24 | MCP Битрикс24 — если рекрутинг ведётся в CRM; гайд: https://guides.labopsai.pro/bitrix24-claude |
| Вручную | Опиши данные текстом: вакансия, этап, количество, причины отказов |

## Ограничения

- Капсула работает с данными, которые ты дал: файл Excel/CSV, Google Таблица, текст в чате или подключение Битрикс24 через MCP. Сама в другие системы не ходит. Если твоя HR-система умеет выгрузку в Excel/CSV — выгрузи и кинь файл.
- Причины отказов — только из данных; пустые поля отмечаются как «причина не указана».
- Доля офферов и срок закрытия — только если эти поля есть в выгрузке.
- Перед загрузкой файла: замени ФИО на Кандидат 1, Кандидат 2 и т.д.;
  убери телефоны, email и паспортные данные.
- Имена кандидатов в отчёт не включаются.
- Если спросишь про 1С: выгрузи отчёт из 1С в Excel и кинь файл в чат.

## Команды

| Команда | Что делает |
|---|---|
| `Воронка` | Начать: выбрать источник данных, задать вопросы о периоде и этапах |
| `Обнови отчёт` | Пересчитать по новым данным |
| `Покажи по рекрутёрам` | Сгруппировать таблицу по рекрутёрам |
| `Покажи по вакансии [название]` | Детальный срез по одной вакансии |
